Intro Astronomy Sims

draft collection — companion to the intro-physics sims

Single-file interactive simulations for an introductory (non-majors) astronomy course. Same house style as the physics sims: an Info panel, a Worked example, an inputs → results layout, and everything self-contained so a page can be dropped into Moodle with an <iframe>.
